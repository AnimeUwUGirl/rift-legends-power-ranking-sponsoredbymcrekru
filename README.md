# Rift Power

Niezależny ranking drużyn grających w Rift Legends.

Strona: [riftpower.pl](https://riftpower.pl)

Składy sprawdzamy w Leaguepedii. Terminarz i wyniki bierzemy z LoL Esports oraz GOL.GG.

## Pasek „Na bieżąco”

Wyniki zakończonych serii trafiają do paska automatycznie z LoL Esports albo Leaguepedii.
MVP z oficjalnych grafik Rift Legends dopisujemy ręcznie w pliku `social-posts.json`.
